Sheetbrief privacy policy

Effective November 13, 2026 · Free local release 0.2.1

Sheetbrief creates campaign reports from CSV/TSV files and spreadsheet cells you choose to import. This policy describes the free Chrome extension release with payments disabled.

Information you provide

Sheetbrief processes the spreadsheet rows, column names, campaign metrics, client names, report titles, currency labels, commentary, and report settings you enter. Imported files may contain financial information or other information you include in their columns. Import only information you have permission to use.

How your information is used

Your data is used to validate rows, calculate metrics, draw charts, filter reports, save local reports, and produce exports you request. Sheetbrief does not automatically read your browsing history, website contents, Google account, or Google Sheets. Pasting cells or choosing a file supplies the data explicitly.

Local storage and retention

Imported report data is processed in the browser. Reports you save are stored in this extension's local browser storage until you delete them, clear the extension's stored data, or uninstall the extension. Unused source columns may remain in saved imports. Unsaved edits are held in the current editor session. Browser profiles and the separate website preview have separate report storage.

Local reports are not password-protected or application-encrypted by Sheetbrief. Protect your browser profile and device. Avoid importing sensitive personal records that are not needed for campaign reporting.

Transmission, sharing, and sales

This free release does not send imported spreadsheets, report settings, commentary, or campaign metrics to the developer, an AI provider, Cloudflare, Supabase, ExtensionPay, or another server. It includes no analytics, advertising, or tracking SDK. We do not sell this information or use it for advertising. Exporting a file or printing a report is an action you control; any later sharing of that exported file is up to you.

Payments

Purchases are disabled in this release. The packaged payment integration is not configured and makes no ExtensionPay requests. There is no checkout or payment-data collection in this free release. If payment features are enabled in a future update, the extension's disclosures and this policy will be updated to explain the provider and information involved.

Support website and GitHub

The public help and privacy pages are hosted on GitHub Pages. GitHub states that visitors' IP addresses are logged for security. If you open a support issue, GitHub receives your post and account details, and the issue is public. See the GitHub Privacy Statement. Visiting these pages or posting an issue does not automatically upload your Sheetbrief reports.

Permissions and executable code

The extension requests the sidePanel permission to open its reporting interface beside browser tabs. It does not request access to all websites. Scripts, fonts, icons, and chart code are packaged with the extension; it does not download executable code from a server.

Your choices

You can edit report settings and commentary, export your data, delete individual saved reports from Saved reports, or remove all local extension data through Chrome's extension settings. Removing this extension also removes its local saved reports. Export before clearing or uninstalling if you want to keep the underlying data.

Support and policy updates

For support or privacy questions, use the Sheetbrief support issue tracker. GitHub issues are public: do not post confidential spreadsheets, client data, credentials, or payment information. You choose what information to send in a support request; do not send sensitive source spreadsheets unless necessary and explicitly requested. Updates to data handling will be reflected in this policy and the store disclosures.

Sheetbrief's use of user data is limited to providing its stated reporting functionality. It does not use or transfer data for advertising, unrelated purposes, or creditworthiness or lending decisions.
