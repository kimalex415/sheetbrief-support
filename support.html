Using Sheetbrief

Create repeatable campaign reports from the spreadsheet you already maintain.

  1. Click the Sheetbrief toolbar icon to open the sidebar.
  2. Choose New report, then upload a CSV/TSV or paste spreadsheet cells including a header row.
  3. Map Date, Campaign, Spend, and Leads. Channel, Qualified leads, and Revenue are optional.
  4. Choose the date format and review any invalid rows before creating your report.
  5. Filter the report, customize the title and client details, and add commentary.
  6. Click Save report to keep it in this browser. Use Update data next month to reuse its settings.
  7. Use Export CSV for data or Print / PDF with the browser's Save as PDF option.

Import format

Use one header row, one currency per dataset, decimal points for numeric fractions, and an explicitly selected date format. The current release supports imports up to 5 MB and 20,000 rows, and up to five locally saved reports subject to browser storage limits.

What is available

The free release uses local data. Direct Google Sheets connections, cloud synchronization, hosted sharing, automatic refresh, subscriptions, and AI summaries are not available. Use copied cells or a CSV export from Sheets.

Keep your reports

Saved reports are local to this browser profile. Deleting extension data or uninstalling removes them. Export first if you need the underlying data later. CSV exports do not contain all report presentation settings.

Contact
